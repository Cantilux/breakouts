Breakouts

A CSS grid for long reads: every child sits in the text column, and one class lets it break out.

.content up to 50ch
.popout content + 2 × 2rem
.feature popout + 2 × 5rem
.full edge to edge
npm install breakouts GitHub npm

These four bands are the page's own grid: resize the window and watch the numbers. On a phone, popout and feature fold back into the text without a media query.

Four widths, one class each

The grid is Ryan Mulligan's named-line pattern: seven column tracks between eight named lines, centred on a reading column. Scroll, and one picture moves through them at this page's real width.

Every child starts in the text. .breakouts > * places each direct child in content, at most 50 characters wide.

.popout steps out a little. The content column plus the --popout track on each side, 2rem at most.

.feature steps out further. Popout plus the --feature track on each side, 5rem at most.

.full runs edge to edge. The whole container. Everything else keeps at least --gap from its edges.

.content, the reading column

The tracks

Each track is a custom property on :root, so any element can resize the grid for its own subtree. popout and feature can shrink to nothing; full never drops below --gap, which is what keeps text off the edge of a phone.

.breakouts {
  display: grid;
  grid-template-columns:
    [full-start] var(--full)
    [feature-start] var(--feature)
    [popout-start] var(--popout)
    [content-start] var(--content) [content-end]
    var(--popout) [popout-end]
    var(--feature) [feature-end]
    var(--full) [full-end];
  row-gap: var(--gap);
}

:root {
  /* the row gap, and the smallest outer gutter */
  --gap: clamp(1rem, 6vw, 3rem);
  /* whatever is left, never less than --gap */
  --full: minmax(var(--gap), 1fr);
  --feature: minmax(0, 5rem);
  --popout: minmax(0, 2rem);
  --content: min(50ch, 100% - var(--gap) * 2);
}

Measured in Chromium with the default system-ui font at 16px. Below about 573px popout and feature are as wide as the text; from about 824px every area has its full size. 50ch is measured in the grid's own font, so another font moves these numbers.

Your proportions

Override a track on any element, not only :root. Keep the gutter term in --content so text still clears the edge.

.longform {
  --content: min(36ch, 100% - var(--gap) * 2);
  --feature: minmax(0, 8rem);
}

A narrower measure for this block alone, and a wider feature track around it.

The rest of the page keeps the defaults.

  • .breakouts

    The container. Every direct child goes into the content column; nested in another .breakouts, it becomes a subgrid.

  • .content

    Spans content. The reading column, at most 50ch. The default for every child; the class places one explicitly.

  • .popout

    Spans popout. Content plus --popout (up to 2rem) on each side.

  • .feature

    Spans feature. Popout plus --feature (up to 5rem) on each side.

  • .full

    Spans full. Edge to edge of the container.

  • .popout-start

    Spans popout-start to content-end. Out to the popout line on the start side only. .popout-left is its physical alias.

  • .popout-end

    Spans content-start to popout-end. Out to the popout line on the end side only. .popout-right is its physical alias.

  • .feature-start

    Spans feature-start to content-end. Out to the feature line on the start side only. .feature-left is its physical alias.

  • .feature-end

    Spans content-start to feature-end. Out to the feature line on the end side only. .feature-right is its physical alias.

  • .full-start

    Spans full-start to content-end. To the container's start edge, ending on the text. .full-left is its physical alias.

  • .full-end

    Spans content-start to full-end. From the text to the container's end edge. .full-right is its physical alias.

  • .breakouts-grid

    The same grid as .breakouts, kept for older markup.

  • .container

    Older helper. A centred wrapper: max-width: 72rem, padding-inline: 1rem.

  • .grid

    Older helper. Three columns with the children in the middle one, minmax(0, var(--container-max-width, 64rem)) wide. .grid--full spans all three.

  • .full-bleed

    Older helper. 100vw wide from a parent centred in the viewport; --left and --right reach one viewport edge. Inside a .breakouts, prefer .full.

  • .breakout

    Deprecated. Aliases of .full-bleed*, removed in the next major version.

No class matches. Try popout, start or grid.

Install

npm install breakouts
# or: pnpm add breakouts · yarn add breakouts · bun add breakouts

With Sass

The sources use the module system, so they need Dart Sass. The pkg: URL needs its Node package importer (Dart Sass 1.71 or newer): --pkg-importer=node on the command line, or new sass.NodePackageImporter() in JavaScript. Without it, add node_modules to the load paths and write @use 'breakouts'.

@use 'pkg:breakouts';   // tokens, reset, typography, grid, utilities

Plain CSS

The full bundle, built with the default settings, readable or minified.

<link rel="stylesheet" href="node_modules/breakouts/dist/breakouts.css">

Each emits its layers in the same order, utilities last, so you can stop at the size you need.

Around the grid, a thin, optional layer

Colour tokens

Every colour is a custom property. Brand and status colours get a dark value 50% lighter (color.scale($lightness: 50%)), so changing a light value changes its dark one too.

  • --color-background#ffffffdark #111111
  • --color-surface#f0f0f0dark #1a1a1a
  • --color-text#111111dark #eeeeee
  • --color-muted#666666dark #aaaaaa
  • --color-primary#0055ffdark 50% lighter
  • --color-secondary#0033aadark 50% lighter
  • --color-accent#ff4081dark 50% lighter
  • --color-success#28a745dark 50% lighter
  • --color-error#dc3545dark 50% lighter
  • --color-warning#ffc107dark 50% lighter
  • --color-neutral-100…900#f8f9fa … #212529same in every mode

Colour modes

No class follows the system. A class on <html> forces a mode, and each mode sets color-scheme so form controls and scrollbars match.

  • <html>Dark when prefers-color-scheme: dark, light otherwise
  • <html class="dark">Always dark
  • <html class="light">Always light, even on a dark system

.dark and .light work on any element: they redefine the tokens for that subtree. Text that inherits its colour from body keeps the page's colour, so give the element its own:

<section class="dark bg-background text-color">…</section>

Utilities

Optional and always emitted last, so on equal specificity a utility beats the grid: class="container px-0" removes the container's padding.

  • Backgroundbg- + background, surface, primary, secondary, accent, muted, success, error, warning
  • Text colourtext-color, text- + the same nine names, text-neutral-100 … -900
  • Marginm-* mt-* mr-* mb-* ml-* mx-* my-*
  • Paddingp-* pt-* pr-* pb-* pl-* px-* py-*
  • Spacing steps0 0 · 1 0.25rem · 2 0.5rem · 3 0.75rem · 4 1rem · 5 1.25rem · 6 1.5rem · auto, margins only
  • Positionposition-static, -relative, -absolute, -fixed, -sticky
  • Stackingz-index-0, -1, -10, -100, -1000
  • Texttext-left, -center, -right, -justify; text-uppercase, -lowercase, -capitalize
  • Fontfont-bold, font-normal, italic, not-italic; leading-tight 1.25, -normal 1.5, -loose 2

The spacing utilities use physical sides: ml-* is the left side in every writing direction (issue #13).

Themes

A theme is a set of colours plus the modules that use them. Load it before the main entry point: on its own, a theme does not emit the spacing and position utilities (issue #10).

@use 'pkg:breakouts/src/theme/chupa-pop' with ($accent: #0f766e);
@use 'pkg:breakouts';
  • Chupa Popprimary #ecb838, secondary #ab4073, accent #196484src/theme/chupa-pop
  • Medicalprimary #4682b4, secondary #9dc183, accent #a9a9a9, muted #6b7280, background #ffffffsrc/theme/medical
  • Tootsie Popprimary #93329e, secondary #f2711c, accent #e94057, muted #ffe5b4; text #fff5e6 on #4f2f4c in every modesrc/theme/tootsie-pop

Each theme takes its own variables: $primary, $secondary, $accent; Medical and Tootsie Pop also $muted and $background; Tootsie Pop also $text. After a theme, @use 'pkg:breakouts' with (…) is a compile error: configure the theme instead.

Sass variables

Every one is !default, set with @use … with (…) on first load. A list value needs parentheses there.

@use 'pkg:breakouts' with (
  $color-primary: #0f766e,
  $font-family-base: ('Inter', system-ui, sans-serif),
);
  • $color-{name}background, surface, text, muted, primary, secondary, accent, success, error, warning: the light values above
  • $color-{name}-darkThe dark values
  • $color-{name}-lightDefaults to $color-{name}: what .light applies
  • $color-neutral-100…900#f8f9fa … #212529
  • $font-family-basesystem-ui, sans-serif; with $font-size-base 1rem and $line-height-base 1.6
  • $headings(h1: 2.25rem, h2: 1.75rem, h3: 1.5rem, h4: 1.25rem, h5: 1.125rem, h6: 1rem)
  • $space-scale(0: 0, 1: 0.25rem, 2: 0.5rem, 3: 0.75rem, 4: 1rem, 5: 1.25rem, 6: 1.5rem, auto: auto)

$headings and $space-scale replace the default map, so list every level you want (issue #11). At runtime, the colour modes set the tokens with selectors more specific than :root: override each mode's selector, or prefer the Sass variables.

Base styles

In the full bundle and in src/base, not in src/core.

  • Resetbox-sizing: border-box everywhere and every margin and padding set to 0, lists included; html and body get width: 100%
  • Bodysystem-ui, sans-serif, 1rem, line height 1.6, --color-text on --color-background
  • HeadingsWeight 600, line height 1.2, margin: 2rem 0 1rem; h1 2.25rem down to h6 1rem
  • Paragraphs, linksmargin: 1rem 0; links in --color-primary, underlined, --color-secondary on hover
  • Inside the gridHeadings and paragraphs that are direct children of .breakouts lose their block margins: the row gap spaces them

Browser support: every current browser. Nesting relies on subgrid (Chrome and Edge 117, Firefox 71, Safari 16); older browsers give a nested grid its own tracks.
